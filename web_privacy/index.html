プライバシーポリシー

「Gmail 一括既読アプリ」（以下、「本アプリ」といいます）は、ユーザーのプライバシーを最重要視し、個人情報の保護に最大限の配慮を行っています。本プライバシーポリシーでは、本アプリにおける情報の取り扱いについて説明します。

1. 外部サーバー非経由の完全ローカル通信

本アプリは、開発者や第三者が管理する中継サーバー（バックエンドサーバー）を一切介しません。ユーザーの端末からGoogleのメールサーバー（imap.gmail.com）へ直接SSL/TLS暗号化通信（IMAPプロトコル）を行います。

2. 取得および利用する情報

  • メールアドレスおよびアプリパスワード： IMAP認証および既読化処理にのみ使用されます。これらの情報は、端末内のセキュアな暗号化領域（iOS: Keychain / Android: Keystore）にのみ保存され、外部サーバーへ送信・収集されることは一切ありません。
  • メールデータ（UID・既読フラグ）： 未読メールの件数取得および既読フラグ（\Seen）の付与に必要な識別子のみをメモリ上で一時的に処理します。メール本文、送信者、添付ファイル等のコンテンツを閲覧・保存・外部転送することはありません。

3. Gmail APIの不使用

本アプリはGmail REST APIを使用せず、標準的なIMAPプロトコルを用いて端末から直接Gmailサーバーと通信します。そのため、Googleアカウント全体の権限付与を要求せず、ユーザー自身が発行した「アプリ パスワード」のみで安全に動作します。

4. 課金処理およびサードパーティサービス

本アプリでは、アプリ内課金（Proプラン）の管理のために RevenueCat を利用しています。購入状態の検証に必要な匿名識別子およびレシート情報のみが処理され、メールアカウントや認証情報が渡されることはありません。

5. データの削除・ログアウト

アプリ内の「アカウント切替」画面からアカウントを削除するか、「すべてのアカウントからログアウト」を実行することで、端末内の暗号化ストレージに保存された認証情報は即座に完全消去されます。また、アプリをアンインストールすることでもすべてのローカルデータが削除されます。

6. 免責事項

本アプリはGoogle LLCが提供する公式アプリではありません。IMAPプロトコルを利用した独立したユーティリティアプリケーションです。
